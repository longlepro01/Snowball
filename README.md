# Snowball
Task-centric Goal Tracking App
Snowball helps you turn small actions into unstoppable progress. Set meaningful goals, break them into milestones, and create quick 5-minute tasks you can do anytime.

When you’re unsure what to tackle, just hit “Roll” — Snowball picks a simple, doable task that gets you moving. Each completed task adds to your momentum — transforming tiny steps into real, lasting progress.

🌨️ Every big goal starts as a small snowball.

Tech Overview:\
🖥️ Front-end: Interactive CLI (with a future optional web version)\
⚙️ Backend: C++ core or Node.js service\
🗄️ Database: SQLite for local use, PostgreSQL for cloud sync
